# Historical pilot grading export

The JSONL/CSV files in this repository directory preserve the original 1,000-review pilot export. They are not the final hero-v1 grading submission.

Download the final hero-v1 evidence ZIP from the release linked in the [current project README](../README.md). Its `grading/` directory contains the 200,000 completed nonempty reviews plus 13 quarantines, final call evidence, source/coverage manifests, membership, ranking, claims and checkpoints. Use that extracted directory with the README's checker commands. The original checker reports `review_required` only for unavailable token usage on 48 failed requests; the exception is disclosed and separately accepted without inventing usage or dropping calls.
